# Fiche idée — Checkliste gratuite "Avant de louer"

## Objectif
Créer une fiche checkliste PDF ou page web téléchargeable gratuitement, destinée aux propriétaires bailleurs à Nice et dans les Alpes-Maritimes, récapitulant tous les diagnostics obligatoires avant mise en location.

## Contenu attendu
- Liste des diagnostics obligatoires (DPE, amiante, plomb, électricité, gaz, termites, assainissement, ERP, Loi Carrez, Loi Boutin)
- Durées de validité de chaque diagnostic
- Cases à cocher pour le propriétaire
- Conseils de mise en conformité
- Contacts ADTI - Ex'im Azur

## Format
- PDF téléchargeable depuis le site
- OU page web dédiée imprimable

## CTA associé
Dans la page `diagnostic-immobilier-location-nice.md`, insérer un bloc CTA invitant au téléchargement.
